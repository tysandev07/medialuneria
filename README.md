# Medialunería Mayorista

PROYECTO: WEB B2B DE MEDIALUNERÍA — LANDING PAGE COMPLETA ORIENTADA A CONVERSIÓN

Actuá como un diseñador UX/UI senior, especialista en CRO (Conversion Rate Optimization), branding gastronómico y desarrollador frontend experto en React, Tailwind CSS y diseño responsive.

Quiero que construyas una landing page completa, moderna, premium y funcional para Medialunería, una fábrica de medialunas artesanales ubicada en Esquel, Chubut, Argentina.

La web debe reproducir fielmente la imagen de referencia adjunta. Utilizala como guía visual principal para la distribución, proporciones, paleta de colores, tipografías, fotografía, tarjetas, espaciados y estructura general.

No quiero una plantilla genérica de panadería. Quiero una web comercial B2B diseñada para captar cafeterías, restaurantes, hoteles, panaderías y comercios gastronómicos que quieran incorporar productos de Medialunería a su negocio.

1. OBJETIVO PRINCIPAL

Convertir visitantes en potenciales clientes mayoristas.

El recorrido de conversión debe ser:

1. El visitante comprende rápidamente que Medialunería es una fábrica proveedora para negocios.
2. Descubre los productos que puede incorporar a su oferta.
3. Comprende cómo funciona la relación comercial.
4. Encuentra razones para confiar en la fábrica.
5. Solicita el catálogo y los precios mayoristas mediante WhatsApp o el formulario.
6. La empresa recibe la consulta con los datos necesarios para continuar la conversación comercial.

El CTA principal de toda la web será:

“Solicitar catálogo y precios”

El CTA secundario será:

“Conocer cómo trabajamos”

Todos los botones deben tener una acción real. No crear botones decorativos sin funcionalidad.
